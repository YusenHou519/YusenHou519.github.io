01 / MENTAL MODEL

先改变问题的坐标系

你不需要重新学习 Transformer。需要改变的是输入、监督信号和泛化目标。

你熟悉的范式

Genome model

DNA sequence → representation
  • 碱基或 k-mer 是 token
  • 序列相对稳定
  • 输出通常是标签、分数或序列
迁移

比赛中的范式

Virtual cell

control distribution + target → response distribution
  • 一个 cell 是 18,533 维状态
  • 表达是随机计数与动态状态
  • 输出是 400 个扰动细胞的分布

COMPETITION OBJECTIVE

P(Xpert) = f ( P(Xcontrol | context), target gene )

没有天然的 control-cell ↔ perturbed-cell 一一配对；预测目标是条件分布。

02 / GLOSSARY

需要掌握的术语地图

目标不是背定义，而是能判断每个概念如何影响训练、验证或提交。

生物与实验

scRNA-seq

分别测量大量单细胞的转录组，得到 cells × genes 计数矩阵，而不是 bulk 平均。

生物与实验

Perturb-seq

把 pooled CRISPR screen 与单细胞 RNA 测序结合，读取大量 perturbations 的全转录组表型。

生物与实验

CRISPRi

通过 dCas9 抑制目标基因转录。通常是程度不一的 knockdown，不等于切断 DNA 的 knockout。

生物与实验

Guide / construct

把 CRISPRi 引导到 target 的序列；同一 target 可有多个 guide，效率可能不同。

生物与实验

NTC

Non-targeting control，不靶向任何基因，用于定义新 context 的未扰动状态。

生物与实验

Basal state

扰动前的细胞状态分布。2026 的 context 信息由 18,400 个 control cells 表达出来。

生物与实验

Context

细胞系及其遗传、表观遗传和培养状态。A/B/C 是匿名 cell lines，不是普通 batch 标签。

生物与实验

GRN / pathway

基因调控网络与功能通路，为从已知 target 外推到未见 target 提供结构先验。

统计与表达

Raw counts

原始非负整数分子计数。模型可在 normalized space 工作，但最终必须提交 raw counts。

统计与表达

Library size

一个细胞所有基因 counts 的总和，同时受到真实 RNA 含量和测序深度影响。

统计与表达

CP10K + log1p

按单细胞总 counts 缩放到一万再取 log1p，常用于模型输入，但不能直接提交。

统计与表达

Sparsity

零可能是真未表达，也可能是有限采样的结果，不应全部解释为 biological dropout。

统计与表达

Count distribution

Poisson、negative binomial、multinomial 决定如何从连续预测生成真实感单细胞。

统计与表达

Pseudobulk

聚合同组细胞形成稳定表达概况，适合估计平均 perturbation delta 和建立基线。

统计与表达

DE / logFC

比较 perturbation 与 control 的变化，既要看显著性，也要看方向和 effect size。

统计与表达

Batch effect

实验、平台和培养流程造成的系统差异；校正过度也可能抹掉真实响应。

机器学习

Delta prediction

预测相对 control 的变化量，再加回 basal state，通常比从零生成完整表达谱稳定。

机器学习

Context generalization

把已知 perturbation effect 迁移到没有扰动观测的新细胞系。

机器学习

Perturbation generalization

预测训练中未见过 response 的 target，通常依赖 ESM2、GO、GRN 等 gene priors。

机器学习

Set-to-set

将一组 control cells 映射为一组 perturbed cells，不假设细胞间一一配对。

机器学习

Distributional loss

Energy distance 或 optimal transport 衡量两个细胞集合的分布差异。

机器学习

Gene embedding

用蛋白序列、GO 或网络位置表达 target，可直接迁移你的 genomic representation 经验。

机器学习

Leakage

同一 dataset、batch、context 或 perturbation 跨越训练与验证，会造成虚高结果。

数据工程

AnnData

单细胞生态的核心容器：X 存表达，obs 存细胞信息，var 存基因信息。

数据工程

H5AD / backed

AnnData 的 HDF5 文件格式；backed="r" 可在不加载完整矩阵时检查大文件。

数据工程

CSR / NNZ

按行压缩的稀疏矩阵与实际存储条目数；完整输出绝不能无脑 densify。

数据工程

Gene alignment

训练集、control 与输出必须按 gene symbol 显式对齐；相同维度不代表相同顺序。

没有匹配的术语，换一个关键词试试。

04 / SCORE SURFACE

六项指标，同等权重

0 是 context-mean baseline，1 是实验 split-half replicate；分数不是百分比。

PDS01

Perturbation discrimination

预测 profile 能否在 300 个 perturbations 中正确区分自己的 target。

perturbation-specific signal
MSE02

Expression accuracy

全基因表达误差，并校正一部分不可避免的抽样噪声。

global expression calibration
NMAE03

DE log-FC accuracy

扰动相对 control 的 fold-change 幅度是否接近真实实验。

effect-size calibration
FID04

Direction fidelity

预测上调的基因是否真的上调，预测下调的是否真的下调。

signed biological effect
REACH05

Direction reach

从最强响应向后看，正确方向能够维持到多深的排名。

ranking depth
JAC06

Significance Jaccard

预测和真实实验判为显著响应的 gene sets 有多少重合。

DE set recovery
过度贴近 controlMSE 可能尚可PDS / DE 失败
制造过强 deltaPDS 可能提高MSE / NMAE 失败
